# Glosario de términos de Dynatrace

El menú y los textos generales de la interfaz se traducen (Problemas, Entidades, Métricas…).
Solo se escriben igual en español y en inglés los nombres propios de objetos o funciones de Dynatrace que aparecen en esta tabla.

| Término           | Se escribe igual | Qué es                                                                                 |
| ----------------- | ---------------- | -------------------------------------------------------------------------------------- |
| Davis             | Sí               | Motor de IA de Dynatrace que detecta problemas y analiza su causa raíz                 |
| Grail             | Sí               | Almacén de datos de la plataforma donde viven logs, eventos y métricas                 |
| DQL               | Sí               | Dynatrace Query Language, el lenguaje de consultas sobre Grail                         |
| SLO               | Sí               | Service-level objective: objetivo de nivel de servicio y su cumplimiento               |
| OneAgent          | Sí               | Agente que se instala en los hosts y recoge sus datos de monitorización                |
| ActiveGate        | Sí               | Componente que enruta el tráfico y monitoriza servicios en la nube y APIs              |
| management zone   | Sí               | Partición del entorno que limita qué entidades y datos ve cada usuario                 |
| Smartscape        | Sí               | Mapa de topología con las dependencias entre hosts, procesos y servicios               |
| PurePath          | Sí               | Traza distribuida de una petición de extremo a extremo                                 |
| Monaco            | Sí               | Herramienta de Dynatrace para gestionar la configuración como código                   |
| Host              | Sí               | Máquina (física, virtual o en la nube) monitorizada, normalmente con OneAgent          |
| Process group     | Sí               | Grupo de procesos iguales que corren en uno o varios hosts                             |
| Browser monitor   | Sí               | Monitor sintético que recorre una web con un navegador real                            |
| HTTP monitor      | Sí               | Monitor sintético que lanza peticiones HTTP a un endpoint y valida la respuesta        |
| Cloud application | Sí               | Carga de trabajo desplegada en Kubernetes, OpenShift u otra plataforma de contenedores |

Solo se añaden términos que la app vaya a usar.
